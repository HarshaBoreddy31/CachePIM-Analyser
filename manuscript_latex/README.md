# CachePIM LaTeX Manuscript Package (Overleaf-Ready)

This directory contains the complete, self-contained LaTeX source files, vector and raster publication figures, and BibTeX bibliography for the CachePIM research manuscript:

**"CachePIM: Reproducible Analytical Exploration of Cache-Aware CPU–Processing-in-Memory Execution"**

## Contents
- `main.tex`: Primary LaTeX manuscript formatted in double-column IEEEtran style.
- `references.bib`: Complete BibTeX bibliography with full citations and DOIs.
- `figures/`: All 9 high-resolution experimental figures (PNG and PDF).

## How to Compile on Overleaf
1. Upload the `manuscript_latex.zip` archive directly to [Overleaf](https://www.overleaf.com/) via **New Project > Upload Project**.
2. Set the compiler to **pdfLaTeX** (default) or **XeLaTeX**.
3. Set the main document to `main.tex`.
4. Click **Recompile**.
