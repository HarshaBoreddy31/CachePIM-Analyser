# How to Record the 4 to 7-Minute Demo Video

You can record the demo video on Windows in 1080p using built-in or free tools:

### Option A: Windows Built-In Screen Recorder (Xbox Game Bar - Fastest)
1. Start the Streamlit dashboard by double-clicking `run_dashboard.bat` (or open `http://localhost:8505` in Chrome/Edge).
2. Press **`Win + Alt + R`** on your keyboard to immediately begin recording.
3. Make sure your microphone is enabled (press **`Win + G`** to check audio capture settings if needed).
4. Follow the script in `DEMO_SCRIPT_AND_WALKTHROUGH.md` (takes ~5 minutes).
5. Press **`Win + Alt + R`** again to finish recording.
6. The MP4 video will be saved automatically in:
   `C:\Users\<username>\Videos\Captures\`

### Option B: Using OBS Studio or Chrome Screen Recorder
- If you have OBS Studio, select **Display Capture** or **Window Capture** for your browser window.

### Submitting the Video
Once recorded:
1. Copy the `.mp4` file into this `demo_video/` directory as `demo_video.mp4` (if under 100 MB).
2. **OR** upload the video to Google Drive or YouTube (as Unlisted) and paste the shareable link in `VIDEO_LINK.txt`.
